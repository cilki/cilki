This crate contains official imagery and digital provenance for all cilki
projects.

## Cryptomarks

Since cilki isn't a legal organization, it owns no trademarks. Instead,
everything "owned" by cilki is cryptographically signed to prove
authenticity. This includes all software artifacts, graphics, domains, etc.

The `cilki` CLI is used to verify artifacts.
